# 08 — Character Concepts v2: Engineered Catchphrases + Sample Mini-Scripts

Each concept below is fully formed against the language harness (`07`): an **engineered catchphrase**
(built to the §9 rules: 2–6 words, singable, ends on belonging/warmth, imitable by a 3-year-old,
shoutable *and* whisperable) and a **sample mini-script snippet** written in child-directed Hebrew —
register (§1), address formula (§4), clinician pauses (§5), word banks (§6), rhyme rules (§7), story
templates (§9). Read the Hebrew aloud; each is meant to be *heard* by a 4-year-old.

**Engineered-pause notation:** `[— 2.5s]` = an engineered expectant pause (clinician rule §5-3) that
stays in the beat timing and is NOT trimmed.

---

## 🥇 שְׁפוֹפוֹן (Shfofon) — the hyrax

### Catchphrase — ENGINEERED

> ## "שְׁפוֹפוֹן פֹּה — אַף אֶחָד לֹא לְבַד!"
> *Shfofon po — af echad lo levad!* · "Shfofon is here — nobody is alone!"

| §9 rule | How it passes |
|---|---|
| 2–6 words | 5 content words (plus the name) ✓ |
| Singable / rhythm | Trochaic 4-beat chant: שפו-פון-פה / אף-א-חד-לא-ל-בד — claps on the beat ✓ |
| Ends on belonging | "אף אחד לא לבד" — the ohana/belonging payload, not a gag ✓ |
| Imitable by a 3-y-o | Open vowels, soft ש/פ/ב/ד consonants, no hard clusters ✓ |
| Shoutable AND whisperable | Shouted = arrival; whispered = the comfort line ✓ |

**Engineering notes:** it leads with the character's name (self-branding), doubles as both the
arrival greeting and the warm resolution line (so it bookends every short), and carries the
found-family theme the research flagged as the stickiest emotional payload.

### Sample mini-script snippet (a colors call-and-response)

```
שפופון:  שָׁלוֹם יְלָדִים וִילָדוֹת! אֲנִי שְׁפוֹפוֹן!      (greeting formula §4)
         מָה זֶה?                                        (point & ask §5-2)
         [— 2.5s]                                        (engineered pause §5-3)
         נָכוֹן! זֶה כַּדּוּר!                            (warm acceptance, rising tone §1)
         כַּדּוּר אָדֹם! אָדֹם כְּמוֹ תַּפּוּחַ!           (expand §5-4, word bank §6)
         אָדֹם, אָדֹם, אָדֹם!                             (repetition ×3 §3)
         [— 2s]
         שְׁפוֹפוֹן פֹּה — אַף אֶחָד לֹא לְבַד!           (catchphrase → warm close)
```

*Voice:* `he-IL-HilaNeural`, warm/rising on "נכון!", whisper the catchphrase if it's the comfort beat.
*Captions:* nikkud on (kids exception), lineHeight ~1.5.

### The character
A rock hyrax (שפן סלע) — native Israeli animal, culturally ownable, unclaimed. Buck teeth always
showing + a fluffy mohawk that droops when sad. Sandy-orange. Mischief: "borrows" shiny things,
returns them with a hug. Cultural moat: strongest.

## 🥈 בּוּ (Bu) — the gentle creature

### Catchphrase — ENGINEERED

> ## "בּוּ בּוּ — אוֹהֵב אוֹתְךָ!"
> *Bu bu — ohev otcha!* · "Bu bu — loves you!"

| §9 rule | How it passes |
|---|---|
| 2–6 words | 3 ✓ |
| Singable / doubling | Name-doubling "בּוּ בּוּ" is the signature coo (§2 reduplication) — pure chant ✓ |
| Ends on warmth | "אוהב אותך" (loves you) — direct affection, the belonging payload ✓ |
| Imitable by a 3-y-o | "בּוּ בּוּ" is babble-simple; the softest consonants in the set ✓ |
| Shoutable AND whisperable | Shouted in play; whispered as the comfort line ✓ |

**Engineering notes:** the name-doubling makes the brand *itself* the sound toddlers imitate (like
Minionese "Bello!"). The creature's antenna glows on the catchphrase — a visual sync cue.

### Sample mini-script snippet (a feelings mini-story)

```
בּוּ:    בּוּ בּוּ! שָׁלוֹם!                              (name-coo greeting)
         בּוּ שָׂמֵחַ!                                    (feeling word bank §6: שמח)
         [בּוּ מְקַפֵּץ שָׁלֹשׁ פְּעָמִים — boing ×3]      (signature gesture)
         אוֹי! נָפַל הַכַּדּוּר...                        (gentle problem, template §9)
         [אָנְטֶנָה שׁוֹקַעַת] בּוּ עָצוּב...              (vulnerability — antenna dims)
         [— 2.5s whisper] בּוּ בּוּ... אוֹהֵב אוֹתְךָ...   (whispered comfort, Bialik aside §8B)
         [חֵיוּך] בּוּ שָׂמֵחַ שׁוּב!                      (warm resolution)
         בּוּ בּוּ — אוֹהֵב אוֹתְךָ!                      (catchphrase, full voice)
```

*Voice:* `he-IL-HilaNeural` + coo/giggle overlay on the "בּוּ בּוּ"; the whispered line drops to the
low-comfort register (§1 tone mapping).

### The character
A soft blobby creature, teal-green, with a single curly antenna whose glowing tip shows its mood
(dims when sad, bright when happy). Mischief: sneezes glitter, knocks things over bouncing, then
helps fix it. Baby-schema appeal: strongest. Risk: needs hard design differentiation from Stitch.

## 🥉 טִפָּה (Tipa) — the little raindrop

### Catchphrase — ENGINEERED

> ## "טִפָּה טִפָּה — יַחַד יָפֶה!"
> *Tipa tipa — yachad yafe!* · "Drop drop — together is lovely!"

| §9 rule | How it passes |
|---|---|
| 2–6 words | 4 ✓ |
| Singable / rhyme | Name-doubling + a clean **-ah/-eh near-rhyme** (טיפה↔יָפֶה) — the simple sibilant-friendly rhyme §7 favors ✓ |
| Ends on belonging | "יַחַד" (together) — the belonging payload ✓ |
| Imitable by a 3-y-o | Soft ט/פ/ה; open vowels; very chantable ✓ |
| Shoutable AND whisperable | Shouted in the splash; whispered in the gentle close ✓ |

**Engineering notes:** it rhymes her own name with "lovely/together," so the brand reinforces the
theme every time. The plip sound "טיפּ!" is her non-word signature.

### Sample mini-script snippet (a gentle water/weather moment)

```
טִפָּה:  טִיפּ! שָׁלוֹם יְלָדִים וִילָדוֹת!               (plip + greeting formula §4)
         אֲנִי טִיפָּה, טִיפַּת מַיִם!                      (self-intro, word bank §6: מים)
         מָה זֶה? ... עָנָן!                              (point & ask §5-2)
         [— 2.5s]                                        (engineered pause §5-3)
         הָעָנָן עוֹשֶׂה גֶּשֶׁם — טִיפּ טִיפּ טִיפּ!        (onomatopoeia §2-3 + repetition ×3)
         [קוֹפֶצֶת, נוֹחַת בְּ"פְּלִיפּ" רַך]              (signature hop + soft plip)
         טִיפָּה טִיפָּה — יַחַד יָפֶה!                   (catchphrase → gentle close)
```

*Voice:* `he-IL-HilaNeural`, softest and gentlest of the three — matches the "calm short" brand
position most tightly.

### The character
A sky-blue raindrop — droplet body IS the head, tiny arms, hops instead of legs, a question-mark
swirl tuft that wiggles. Mischief: drips and splashes where she shouldn't, then helps clean up.
Calm/parent-trust fit: strongest; cleanest silhouette at tiny phone scale. Risk: mildest chaos, so
attachment may build slower; least "creature"-ownable.

**My recommendation stands: שְׁפוֹפוֹן (Shfofon) the hyrax** — the only concept that owns a *position*
(a native Israeli animal for Hebrew kids) rather than just a look, with a strong belonging catchphrase
and a real mischief engine. **בּוּ** is the pick if you want maximum cute-appeal and merch; **טִיפָּה**
if you want the purest "calm, guilt-free" brand.
