## The headline: a first-class Hebrew pronunciation layer

The single biggest deliverable is **`tools/hebrew_pronounce.py`** — a reusable Hebrew layer that
*every* Hebrew voice generation now passes through. It was the user's idea ("Maybe add a layer in
hebrew that responsible for adding ניקוד?"), and it's the right architecture.

**The problem it solves:** unpointed modern Hebrew is ambiguous — the same letters read as several
words. A TTS left to guess misreads exactly the words an Israeli client cares about (letter-names,
code-switches). The bakeoff proved it: the auto-vocalizer read **החית** as *"ha-CHAY-it"* (the
animal) instead of the letter-name **חֵית** (*kheyt*). An avatar that mispronounces a letter reads
as broken to a native ear, no matter how good the lip-sync.

**The layer owns three jobs, in a fixed order:**

1. **Auto-nikud** — phonikud ONNX (via `nikkud_g2p.py`) points the verse (the general 95%).
2. **Pronunciation dictionary** — pins known-misread words to their exact pointed form. **Applied
   AFTER nikud** (the nakdan re-vowels pointed input, so pins must run last to win). Prefix-aware:
   matches a pin as a suffix behind conjunction letters (וְהָרִישׁ = "and-the-resh"), keeping the
   vocalizer's pointed prefix; splits trailing punctuation first.
3. **Code-switch policy** — foreign words Israelis say in English (WhatsApp, email) stay in LATIN
   so edge-tts reads them English. Hebrew-script וואטסאפ gets mangled by the nakdan, so it never
   reaches it.

**Front door:** `hebrew_pronounce.to_tts(text)` → the exact string fed to edge-tts. Deterministic,
free, offline. ElevenLabs stays the documented last-resort upgrade (not used).

**The dictionary is the accumulated Israeli-ear knowledge of the engine.** Extend it one line at a
time whenever QA surfaces a misread. Current letter-name pins (all user-QA'd):
- חֵית (kheyt — was "chayit") · עַיִן (ayin) · **רֶשׁ (resh, segol no-yod)** — neither "reysh" nor
  phonikud's "reesh" sounded right to a native ear; the segol reading is the modern Israeli one.

**Now wired everywhere:** `gen_voice_edge.py --nikkud` routes through it (was a bare
`nikkud_g2p.add_nikkud` call), so `/make-ad`, `/make-short`, and the avatar track all get it.

## The avatar bakeoff — what we proved, and what we deferred

Goal: prove a photo→avatar render can lip-sync the guttural Hebrew script (ח/ע/ר-dense + a
code-switch). Spend was stated before any render.

**Result: omnihuman RENDERED + MOVES** (`fal-ai/bytedance/omnihuman`, $0.14/s). A 15.6s clip
(`media/projects/_bakeoff-talk/omnihuman.mp4`, committed — paid non-reproducible pixels). User
eyeballed it: **lip-sync "good, not perfect"; the guttural *sound* was the bigger problem** — which
is what the pronunciation layer fixes.

  not under `fal-ai/`; the `fal-ai/` prefix 404'd). Fabric is GA, live, ungated per its model page.
- **Motion gate false-negative** — the old whole-strip probe + a Windows text-mode pipe (`\r\n`
  translation) corrupted byte offsets and called a real talking head "STATIC". Now mouth-region
  weighted, decoded mp4→rawvideo in **binary**. Recalibrated gate on the omnihuman render:
  mouth=13.39 / whole=8.19 / ratio=1.64 → **moved=True**.

**Deferred (user's call):** the fabric re-run ($2.12 derived) and the whole lip-sync *quality*

## The ad scaffold generator (the template system)

**`tools/new_ad.py`** — one command scaffolds a complete, contract-valid `/make-ad` project:
`brief.md` + `script.md` + a `beats.json` (mode:"ad") that **passes `validate_ad_beats` on first
emit** + a compile-ready TSX comp stub. Pre-filled from the vertical's lexicon (register, address
pronoun, edge-tts voice, hook styles, CTA + the CTA to never use, magic phrases).

**The point: the generator enforces the hard gates at emit time, not after.** Real defects it
caught while building the demo, and now bakes in:
- **Hook gate** — hook must land <2s and match the declared style. (First default hook was too
  long; the working one is the 3-word **"נמאס לשלם?"**, lands 1.35s.)
- **Legal disclosure** — a sale (`oldPrice`) auto-adds a Consumer Protection §15/§2 scope +
  total-price block. (First emit FAILED without it.)
- **Pacing** — speech-driven windows (~2.7 w/s + onset + floor, 0.5s gaps) so no OVERFLOW / no
  VO overlap (the timing audit caught my too-tight gaps).
- **Proof line** — emits a Hebrew TODO, never the raw English lexicon hint.

RTL captions, word-exact sync, the 11-vertical lexicon, and hook-craft gating already existed and
are battle-tested (3 shipped ads); this session added the *scaffold* layer on top.

## The demo ad: `shorts/ad-5-noa-studio`

A demo women's hair salon (feminine register, female HilaNeural voice) — built to exercise the
pronunciation layer in a real ad.

```
נמאס לשלם?  →  סטודיו נועה.  →  תספורת + פן במחיר השקה  →  המחיר כולל עיצוב מלא — בלי הפתעות בקופה.  →  קבעי תור.
```

- **First real ad to generate voice through `hebrew_pronounce`** (`--nikkud`) — every line fully
  pointed, female voice, no OVERFLOW, contract **PASS** with real word-timings.
- Registered as `Ad5NoaStudio` (17.11s, `npm run gen` verified).
- **Status: scaffold + voice done. The TSX visuals are a STUB** (empty scenes with FILL-ME markers)
  — the per-beat visuals (hook card, PriceBadge with the 149/220 math, freier-proof, tappable
  WhatsApp end card) + release-gate + QA + render are the remaining craft pass, awaiting the user.
