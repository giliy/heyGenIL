## The timing model this phase stands on (read carefully)

Voice is **not** run in Phase 2. But the composition must be authored against **planned timings that
P3 will replace with real trimmed ones** — and the placeholder `vo.gen.ts` the comp imports must be
self-consistent so the QA frames are meaningful *now*.

- **`reading.json`** = the unit manifest `gen_voice_reading.py` consumes in P3 (`{voice, units:[{id,
  grapheme, sound, role}]}`). Authored here from `nikkud_data.py` (single source of truth).
- **`beats.json`** = the contract + the authored VO. Its `vo[].units[]` carry the **planned**
  per-unit windows (beat start + an engineered onset inside the clip). These satisfy the
  `validate_reading_beats` conditional units audit *and* seed the placeholder `vo.gen.ts`.
- **`vo.gen.ts`** = what `Read1Kamatz.tsx` imports. In P3 it is **AUTO-GENERATED** by
  `gen_voice_reading.py --emit-ts` with real trimmed bounds. In Phase 2 it is a **hand-authored
  placeholder** carrying the same shape (`VoLine[]` with `units`), matching `beats.json` — clearly
  marked "placeholder, regenerated by P3". The comp reads `VO`, so it renders meaningfully now and
  re-syncs for free after voice.
- The composition **positions tiles/captions from `VO` times**, never from hardcoded seconds, so the
  P3 overwrite re-times everything without a code change.

## Deliverable 1 — `reading-shorts/read-1-kamatz/` (the data seams)

New top-level dir, parallel to `shorts/` (master plan §1.2 — the artifact contract differs: a
`curriculum.json` + `reading.json` per video, generated *from* the curriculum).

### 1a. `curriculum.json`
Resolved per-video teaching spec, **derived from `tools/nikkud_data.py` kamatz row** (never
hand-invented vowels). Emit it by reading the row so the file and the source can never drift:
`order/key/sign/name_he/sound/targetLetters/cv/blendWords/musicBed` — and `mnemonic: null` (findings
§2/E: **do NOT fabricate** per-sign child mnemonics). A tiny inline Python `--emit` against
`nikkud_data.get_nikkud("kamatz")` writes the file (no new tool needed).

### 1b. `script.md`
The beat sheet, **register 5–7** (master plan §1.4 register raise — `character.json` targets 3–5
motherese; keep the character/voice/catchphrase but write **short directive prompts** +
call-and-response "now you say בָּ", **NOT toddler cooing**). Six beats per master plan §6, ~34s:
hook → teach-isolated → teach-cv → blend → read-word → call-response. Each beat lists: on-screen
visual, the VO line (pointed Hebrew for edge-tts), and the highlight behavior. No CTA outro
(reading inherits mode:"kids" no-CTA). Loop **relaxed** (`loop:false`) — a reading short is a
one-shot lesson; the call-and-response is the payoff, not a loop (master plan §5 seamless-loop note).

### 1c. `reading.json` (unit manifest for `gen_voice_reading.py`)
`{voice:"he-IL-HilaNeural", units:[…]}`, `role ∈ isolated|cv|blend|word`:
- **isolated:** בָּ (the sign alone).
- **cv:** the teach-cv set בָּ/מָּ/קָּ (subset of the curriculum `cv` row — 3 fit the beat window).
- **blend:** בָּבָּא with `syllables:["בָּ","בָּא"]` (the curriculum `blendWords` split; stitched
  back-to-back, no gaps = continuous blending per findings §1).
- **word:** בָּבָּא (one continuous clip → whole-word highlight, no units).

### 1d. `beats.json` (mode:"reading")
The contract. Base shape (`id/title/format/vo`) + `mode:"reading"` + `language:"he"` + the
`reading{}` block (`nikkud:"kamatz"`, `sign:"בָּ"`, `sound:"a"`, `targetLetters`,
`progression:["isolated","cv","blend","word"]`, `anchorWords`) + the 6 `beats[]` (hook /
teach-isolated / teach-cv / blend / read-word / call-response) in progression order + `vo[]` lines
whose isolate/CV lines carry **planned `units[]`** (⊆ line span, sorted, non-overlapping — so the
validator's conditional audit passes). `durationSec ≈ 34`. **Validate:**
`python tools/contracts.py reading-beats reading-shorts/read-1-kamatz/beats.json` → **OK**.

## Deliverable 2 — `remotion/src/shots/read-1/Read1Kamatz.tsx`

Clone the **short-18 pattern** (`AbsoluteFill` bg, `Sequence` per beat, `Captions lines={VO} y plate
rtl kidsNikkud`, `ProgressBar`) but with the **reading kit** from `lib/reading.tsx`. All timing read
from `VO` (`useCurrentFrame`/`fps` → global `t`), never hardcoded.

- **Visual ($0 in-TSX):** a warm kids scene — dark warm bg (brand d900/glow), a **בּוּ illustrated
  tile** (a flat in-TSX koala token: yellow rounded body + cream ears, the locked silhouette
  signature — the ears) beside the hero tile. **No AI stills** (master plan §7 allows in-TSX for the
  pilot). The hero is the letter tile, not a generated image.
- **hook (frame 0 composed):** בּוּ tile + the huge target sign בָּ already visible (findings §1
  frame-0 rule; brand §6 frame-0-is-thumbnail). Whole-word caption.
- **teach-isolated:** `GraphemeTile` בָּ huge, stable nikkud sign color overlay; `soundWindow` =
  the line's `units[0]` → the whole pointed letter scale-pops + tints in sync with the spoken "ba".
- **teach-cv:** `SyllableTile`s בָּ מָּ קָּ, **one at a time**, each `soundWindow` = its unit → each
  צירוף pops as spoken (touch-and-say).
- **blend:** the two syllable tiles **slide together** into בָּבָּא while the highlight **sweeps**
  across syllables — each syllable's `soundWindow` from the stitched blend `units[]` (back-to-back,
  no gaps). Render as two `SyllableTile`s whose x offsets interpolate together + the caption's
  per-grapheme `units` path lights the sweep.
- **read-word:** whole word בָּבָּא, one continuous clip → **whole-word pop** via the existing
  Captions path (no `units[]` on this line — the fallback the contract allows). בּוּ celebrates.
- **call-response:** "אַתֶּם!" (now you!) + an **engineered pause** — reuse the pilot's `הִמְהוּם`
  hum trick (edge-tts rejects bare `...`, NoAudioReceived). No tile highlight during the pause
  (silence → none lit). Settles; loop relaxed (`loop:false`).
- `compositionConfig`: `id:"Read1Kamatz"`, 1080x1920@30, `durationInSeconds ≈ 34`.

**Registration:** `read-` prefix is already mapped in `gen-registry.mjs typeOfGroup()` (P1) →
`faceless`. Run `cd remotion && npm run gen`. Sanity-check the registered `durationInSeconds` ≈
last-speech + ~2.5s (no dead tail / truncation — the ads lesson, master plan §5 step 1).

## Deliverable 3 — phone-scale QA (the gate)

```
cd remotion && npm run gen
node scripts/qa_frames.mjs Read1Kamatz 0,<beat-boundaries+each-unit-highlight>,<last> --scale=0.333
```
**READ every small JPG.** Reading-specific checklist (on top of the standard one, master plan §5.2):
- **Highlight == sound:** step frames across each `units[]` window; the lit grapheme is the one being
  spoken. (The product's promise.)
- **No two graphemes lit at once; none lit in silence** (hook intro gaps + the call-response pause).
- **Nikkud legibility:** points don't clip at `lineHeight 1.5`; tile clears SAFE (bottom 500 / right
  160); the kamatz sign reads clearly in its stable color.
- **Bidi:** Hebrew + any Latin/phonetic label tokens didn't reorder (anchorRtl/RLM/isolate in lib).
- **Frame 0 composed** (target sign visible); call-response **pause present** (a frame inside it
  shows no highlight).

Verdict recorded explicitly in the structured output: **PASS** = every check green, or **FAIL** +
the specific frame/check that broke.
